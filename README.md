# Microsoft Entra ID Role Assignment

## Objective

Assign a Microsoft Entra ID directory role to a cloud user and verify the role assignment.

## Step 1: Review Existing Role Assignments

Reviewed **Taylor Morgan's** account and confirmed that no directory roles were currently assigned.

![](images/01-no-directory-roles-assigned.png)

## Step 2: Assign the Directory Readers Role

Selected and assigned the **Directory Readers** role to provide read-only directory access while following the principle of least privilege.

![](images/02-select-directory-readers-role.png)

## Step 3: Verify the Role Assignment

Confirmed that the **Directory Readers** role was successfully assigned directly to the user.

![](images/03-directory-readers-role-assigned.png)
